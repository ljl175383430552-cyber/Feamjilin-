# 扫描朗读（ScanReader）

一个安卓应用：打开软件后使用相机对准画面，点击「扫描并朗读」按钮，应用会识别画面中的文字（支持中文和英文），识别成功后播放一声提示音效，并用中文语音朗读出来。

## 功能

- 打开应用即启动相机实时预览（首次使用需授权相机权限）
- 点击「扫描并朗读」拍摄当前画面并进行文字识别
- 使用 Google ML Kit 中文文字识别模型，**完全离线**，无需联网
- 识别成功后播放提示音效，然后用系统中文语音（TTS）朗读识别结果
- 识别结果同时显示在屏幕下方，可随时点击「停止」中断朗读

## 技术栈

| 模块 | 方案 |
| --- | --- |
| 相机 | CameraX（Preview + ImageCapture） |
| 文字识别 | ML Kit `text-recognition-chinese`（离线，模型打包进 APK） |
| 语音朗读 | Android 系统 `TextToSpeech`，语言设置为简体中文 |
| 音效 | `ToneGenerator` 成功提示音 |

## 构建

需要 JDK 17+ 和 Android SDK（compileSdk 34）。

```bash
cd android-app
./gradlew assembleDebug
```

生成的 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`，可直接安装到 Android 8.0（API 26）及以上的手机。

## 使用说明

1. 安装并打开应用，授权相机权限
2. 将相机对准想要朗读的文字（书本、招牌、屏幕等）
3. 点击「扫描并朗读」，听到"嘀"一声表示识别成功，随后开始中文朗读
4. 点击「停止」可中断朗读

> 提示：朗读依赖系统 TTS 引擎的中文语音包。绝大多数国产手机自带；如提示不支持中文，请在系统「设置 → 无障碍/语言 → 文字转语音」中安装中文语音数据。
