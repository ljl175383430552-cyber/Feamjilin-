# 屏幕锁（防误触锁屏应用）

一个防误触的 Android 应用：倒计时结束后，在**任意界面 / 应用上层**盖一层全屏透明的触摸拦截层——画面照常显示、视频照常播放，但点击、滑动全部无效，防止误触。

## 使用流程

1. 首次打开需要授予「悬浮窗」（在其他应用上层显示）权限；
2. 打开软件后自动开始 **30 秒倒计时**（通知栏同步显示剩余秒数）；
3. 在倒计时结束前，切换到你想停留的界面或应用（比如正在播放的视频）；
4. 倒计时结束后自动 **锁定触摸**：屏幕上不显示任何额外内容，当前画面原样呈现、屏幕保持常亮，但所有点击 / 滑动都不再生效（锁定过程完全隐形，仅通知栏可以看到状态）；
5. **长按屏幕 5 秒** 解开锁定限制（中途松手则重置，解锁成功会有提示）。也可以回到「屏幕锁」应用里点「解除锁定」，或提前点「取消倒计时」。

## 构建

需要 JDK 17+ 和 Android SDK（`compileSdk 34`）。设置好 `ANDROID_HOME` 环境变量后执行：

```bash
cd android
./gradlew :app:assembleDebug
```

生成的 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`，安装到手机即可使用：

```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```

- 最低支持 Android 7.0（API 24）
- 语言：Kotlin，无第三方依赖（仅 AndroidX 基础库）

## 技术说明

- 锁定是通过 `SYSTEM_ALERT_WINDOW` 权限 + `TYPE_APPLICATION_OVERLAY` 实现的一个完全隐形的全屏 View（无任何可见元素），由前台服务（`LockService`）管理，消费所有触摸事件；
- 悬浮窗无法拦截系统级操作（Home 键、导航手势、电源键、状态栏下拉在部分机型上仍可用），主要用于防止误触屏幕内容；
- 锁定期间通知栏常驻一条通知显示状态，倒计时期间显示剩余秒数。
